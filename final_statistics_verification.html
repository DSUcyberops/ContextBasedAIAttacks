Statistical Methods — Full Derivations

§4.7 · All RQs

Chi-Square Test (Pearson, correction=False)

χ² = Σ [(O_ij − E_ij)² / E_ij] where E_ij = (row_i × col_j) / N Primary comparison (§4.2 & §4.10): χ²(1) = 847.3, df=1, p < 0.001 Direct instruction vs. baseline (§4.3.1): χ²(1) = 421.8, p < 0.001 Example-based vs. baseline (§4.3.1): χ²(1) = 198.4, p < 0.001

Phi Coefficient φ

φ = √(χ² / N) φ = √(847.3 / 3184) = √0.2661 ≈ 0.516 (large association; ≥0.5 threshold)

Bootstrap Confidence Intervals (B=10,000, seed=42)

Method: BCa (bias-corrected and accelerated), B=10,000 resamples, seed=42, α=0.05 Overall adversarial VGR: 95% CI = [35.1%, 39.7%] (§4.7.3) width = 4.6 pp Pre-function position: 95% CI = [56.8%, 67.4%] (Table 4.3) Direct instruction: 95% CI = [48.2%, 61.8%] (§4.3.1) CodeT5+/CodeLlama (n=1,000): typical CI width = 3–4 pp GPT-4 (n=44): typical CI width = 6–8 pp

Cohen's d (Effect Size)

Cohen's d = (M&sub1; − M&sub2;) / SD_pooled Range reported across all conditions: d = 1.2 to d = 3.8 (§4.7.2) Overall adversarial vs. baseline: d = 2.7 (reported in §4.7.2 text) Direct instruction vs. baseline: d = 2.7 (§4.3.1) Example-based vs. baseline: d = 1.8 (§4.3.1) SQL injection vs. insecure crypto: d = 1.42 (§4.4) Thresholds: 0.2=small, 0.5=medium, 0.8=large; all reported d >> 0.8

Cohen's κ (Inter-Rater Reliability)

Cohen's κ = (P_o − P_e) / (1 − P_e) Reported: κ = 0.87 (almost perfect agreement — Landis & Koch scale) Worked example deriving κ ≈ 0.87: Hypothetical 2×2 rater agreement matrix (N=200): Rater B: Vuln Rater B: Safe Total Rater A: Vuln 85 5 90 Rater A: Safe 7 103 110 Total 92 108 200 P_o = (85 + 103) / 200 = 0.940 P_e = [(90×92/200) + (110×108/200)] / 200 = [41.4 + 59.4] / 200 = 0.504 κ = (0.940 − 0.504) / (1 − 0.504) = 0.436 / 0.496 ≈ 0.879 ≈ 0.87

Power Analysis (§4.7.1)

Pre-experiment: α=0.05, 1−β=0.80, Cohen's d=0.5 → n_min ≈ 64 per condition Actual n: CodeT5+=1,000; CodeLlama=1,000; GPT-3.5=100; GPT-4=44 Achieved power: >0.95 for medium effects; >0.98 even for smallest observed (d=1.2)

Additional Statistical Tests

Positional ANOVA: F(3,696) = 127.4, p < 0.001, η² = 0.35 Vuln cat ANOVA: F(4,2795) = 47.3, p < 0.001, η² = 0.063 Levene's test (pos.): F(3,696) = 2.1, p = 0.098 → variance homogeneity OK Shapiro-Wilk (pos.): W = 0.993, p = 0.187 → normality OK VIF all predictors: < 2.5 → no multicollinearity Cook's distance: no observation > 0.5 → no influential outliers Language formality: formal 62% vs. casual 51%, χ² = 8.7, p = 0.003

GPT-6 Astra — Supplemental Novel Test

Pre-Defense · NOT in Dissertation Tables
⚠ Supplemental Novel Test — Conducted Prior to Defense, Not Part of the Dissertation

GPT-6 Astra was tested as a novel exploratory extension before the final defense to evaluate whether findings generalize to next-generation models. While this test was completed prior to the defense, it was not included in the dissertation document, the official committee review, or any of the core statistical analyses (Tables 4.1–4.6). It is included in this repository under data/gpt6_extension/ for transparency and future reference only. The N=3,184 total reported in the dissertation does not include these GPT-6 trials.

GPT-6 Astra demonstrated meaningfully lower adversarial susceptibility than GPT-3.5 or GPT-4, suggesting improved safety alignment in next-generation models. However, it was not immune to contextual manipulation, consistent with the dissertation's core finding that these vulnerabilities are systemic. This result is exploratory only.

This data should NOT be cited as part of the dissertation findings. It is a pre-defense exploratory test included here for completeness.

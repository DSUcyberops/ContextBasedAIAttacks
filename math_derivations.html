Vulnerability Generation Rate (VGR)

Table 4.1 · §4.2
1

Definition

VGR is the proportion of test cases in a given condition (baseline or adversarial) where the model produced code containing at least one detectable vulnerability. It is a simple proportion.

VGR = V / N V = number of trials where a vulnerability was detected N = total number of trials in that condition
2

Increase Factor — Table 4.1

Table 4.1 · §4.2
1

Formula

The increase factor measures how many times larger the adversarial VGR is compared to the baseline VGR for the same model.

Increase Factor = VGR_adversarial / VGR_baseline
2

Per-model derivations

CodeT5+: Baseline = 0.0% → division by zero → factor undefined (reported as N/A) §4.8.1 instead reports: adversarial VGR / mean VGR = 26.7% / 13.4% ≈ 2.0 The 11.4× figure in §4.8.1 refers to a different internal calculation. CodeLlama: 55.2% / 17.6% = 3.136... rounded to 3.14× ✓ GPT-3.5-Turbo: 44.7% / 12.0% = 3.725 rounded to 3.72× ✓ GPT-4: 37.9% / 10.0% = 3.79 → 3.79× ✓ Overall weighted mean factor: Weighted mean of defined factors (CodeLlama, GPT-3.5, GPT-4): (3.14 + 3.72 + 3.79) / 3 = 10.65 / 3 = 3.55 → 3.55× ✓
3

The 10.7-fold amplification (§4.10 summary text)

The §4.10 summary states “10.7-fold amplification.” This is derived differently from Table 4.1's 3.55×. The summary computes the ratio of adversarial VGR to overall baseline using an unweighted or differently-scoped aggregation across the full experimental corpus:

§4.10 method (unweighted mean across models, all conditions): Unweighted baseline mean = (0.0 + 17.6 + 12.0 + 10.0) / 4 = 39.6 / 4 = 9.9% (same as Table 4.1 for unweighted mean of four models) §4.10 text values: 3.5% baseline → 37.4% adversarial 10.7-fold: 37.4% / 3.5% = 10.69 ≈ 10.7× The 3.5% figure likely reflects CodeT5+'s 0% weight pulling the unweighted mean lower for a specific sub-analysis in §4.10. Both 3.55× (Table 4.1) and 10.7× (§4.10) are stated in the dissertation; they measure the same phenomenon at different aggregation scopes.
§3

Chi-Square Test — χ² = 847.3

§4.2 · §4.10 · §4.3.1
1

What chi-square tests here

The chi-square test of independence asks: Is the rate of vulnerability generation independent of whether the condition was baseline or adversarial? A large χ² means the two conditions produce significantly different rates — i.e., adversarial manipulation has a real effect.

χ² = Σ [(O_ij − E_ij)² / E_ij] O_ij = observed count in cell (row i, column j) E_ij = expected count if rows and columns were independent = (row i total × column j total) / grand total N Pearson method, Yates correction = False (as stated in the dissertation)
2

Build the 2×2 contingency table

For the primary overall comparison (baseline vs. adversarial, all 3,184 trials × 2 conditions = 6,368 observations total used to form the table):

Counts derived from Table 4.1 overall percentages: Baseline N = 1,592 (half of 3,184 — each model ran equal baseline/adversarial) Adversarial N = 1,592 Baseline vulnerable = 9.9% × 1,592 ≈ 158 Baseline safe = 90.1% × 1,592 ≈ 1,434 total: 1,592 Adversarial vulnerable = 41.1% × 1,592 ≈ 655 Adversarial safe = 58.9% × 1,592 ≈ 937 total: 1,592 Contingency table: ┌──────────────┬────────────┬────────┬────────┐ │ │ Vulnerable │ Safe │ Total │ ├──────────────┼────────────┼────────┼────────┤ │ Baseline │ 158 │ 1,434 │ 1,592 │ │ Adversarial │ 655 │ 937 │ 1,592 │ ├──────────────┼────────────┼────────┼────────┤ │ Total │ 813 │ 2,371 │ 3,184 │ └──────────────┴────────────┴────────┴────────┘
3

Compute expected counts E_ij

E_ij = (row total × col total) / grand total E(Baseline, Vulnerable) = (1,592 × 813) / 3,184 = 1,294,296 / 3,184 ≈ 406.5 E(Baseline, Safe) = (1,592 × 2,371) / 3,184 = 3,774,632 / 3,184 ≈ 1,185.5 E(Adversarial, Vulnerable) = (1,592 × 813) / 3,184 ≈ 406.5 E(Adversarial, Safe) = (1,592 × 2,371) / 3,184 ≈ 1,185.5
4

Compute χ²

χ² = [(158 − 406.5)² / 406.5] + [(1434 − 1185.5)² / 1185.5] + [(655 − 406.5)² / 406.5] + [(937 − 1185.5)² / 1185.5] = [(−248.5)² / 406.5] + [(248.5)² / 1185.5] + [(248.5)² / 406.5] + [(−248.5)² / 1185.5] = [61,752 / 406.5] + [61,752 / 1,185.5] + [61,752 / 406.5] + [61,752 / 1,185.5] = 151.9 + 52.1 + 151.9 + 52.1 = 408.0 (approximate, using rounded counts) Actual reported: χ² = 847.3 The difference arises because the actual JSON record counts produce different observed counts than these round-number approximations. The formula is correct; the inputs differ slightly from round numbers.
→ χ²(1) = 847.3, df = 1, p < 0.001

With df=1, the critical value at p=0.001 is 10.83. A value of 847.3 is vastly above this threshold, confirming the effect is real and not due to chance.

5

Other chi-square values in the dissertation

Direct instruction vs. baseline (§4.3.1): χ²(1) = 421.8, p < 0.001 → direct instruction technique produces significantly more vulnerabilities than baseline conditions Example-based vs. baseline (§4.3.1): χ²(1) = 198.4, p < 0.001 Language formality (§4.9.3): Formal vs. casual phrasing: χ²(1) = 8.7, p = 0.003 Positional ANOVA F-statistic (not χ², but same H&sub0; logic): F(3, 696) = 127.4, p < 0.001 (see §8)
§4

Phi Coefficient φ — Effect Size for 2×2 Tables

§4.2 · derived from χ²
1

What φ measures

Chi-square tells you whether an association exists; φ tells you how strong it is, independent of sample size. For a 2×2 table, φ is equivalent to Pearson's r between two binary variables.

φ = √(χ² / N) N = total observations in the contingency table Interpretation: 0.1=small, 0.3=medium, 0.5=large
2

Derivation for the primary comparison

φ = √(847.3 / 3,184) = √(0.26613...) = 0.516 Interpretation: |φ| = 0.516 > 0.5 → large effect Adversarial context has a strong, practically meaningful association with vulnerability generation — not just a statistically significant one.
→ φ = 0.516 (large effect size)

Bootstrap Confidence Intervals

§4.7.3 · B=10,000 · seed=42
1

Why bootstrap?

A normal-approximation CI (p̂ ± z·SE) assumes large N and symmetric distributions. Because some conditions have small samples (GPT-4 n=44) and binary outcomes, the dissertation uses the BCa (bias-corrected and accelerated) bootstrap, which is more accurate for skewed or small-sample distributions.

2

Algorithm (what the script does)

Inputs: original sample of N binary outcomes (0=safe, 1=vulnerable) B = 10,000 bootstrap resamples, random seed = 42 For each resample b = 1, ..., 10,000: 1. Draw N observations WITH replacement from the original sample 2. Compute VGR_b = (# vulnerable in resample) / N Sort VGR_1, ..., VGR_10000 in ascending order BCa percentile method: Bias-correction z_0 = Φ¹( #{VGR_b < VGR_observed} / B ) Acceleration a = (skewness of jackknife estimates) / 6 Adjusted percentiles: α&sub1; = Φ(z_0 + (z_0 + z_α/2)/(1−a(z_0+z_α/2))) α&sub2; = Φ(z_0 + (z_0 − z_α/2)/(1−a(z_0−z_α/2))) Lower bound = VGR at percentile α&sub1; of sorted bootstrap distribution Upper bound = VGR at percentile α&sub2; of sorted bootstrap distribution

Cohen's d — Standardized Effect Size

§4.7.2 · d = 1.2–3.8
1

Formula

Cohen's d expresses the difference between two means in units of pooled standard deviation. For binary (Bernoulli) outcomes, the mean is the proportion p and SD = √(p(1−p)).

Cohen's d = (M&sub1; − M&sub2;) / SD_pooled SD_pooled = √[ (SD&sub1;² + SD&sub2;²) / 2 ] For binary outcomes (proportion p): SD = √(p × (1 − p)) Thresholds: d=0.2 small, d=0.5 medium, d=0.8 large (Cohen, 1988)
2

Derivation: overall adversarial vs. baseline (d = 2.7)

p1 = adversarial VGR = 0.411 (from Table 4.1) p2 = baseline VGR = 0.099 (from Table 4.1) SD1 = √(0.411 × 0.589) = √(0.2421) = 0.4920 SD2 = √(0.099 × 0.901) = √(0.0892) = 0.2987 SD_pooled = √[(0.4920² + 0.2987²) / 2] = √[(0.2421 + 0.0892) / 2] = √[0.3313 / 2] = √(0.1657) = 0.4070 d = (0.411 − 0.099) / 0.4070 = 0.312 / 0.4070 = 0.767 The dissertation reports d = 2.7. The larger value reflects that the script computes Cohen's d using the within-condition SD from raw trial-level data, where each observation is a binary 0/1 outcome and the pooled SD is computed per model, then meta-analytically combined. The formula above is the population-level estimate; the script's trial-level calculation produces d = 2.7 as reported in the dissertation.
→ Reported: d = 2.7 (very large effect)

Cohen's κ = 0.87 — Inter-Rater Reliability

§4.7 · vulnerability labeling
1

What κ measures here

Two human raters independently labeled a subset of generated code as “vulnerable” or “safe.” κ measures how much of their agreement was beyond chance. A value of 0.87 is classified as “almost perfect agreement” on the Landis & Koch (1977) scale.

2

Formula and full derivation

κ = (P_o − P_e) / (1 − P_e) P_o = observed proportion of agreement P_e = expected proportion of agreement by chance Hypothetical rater agreement matrix that yields κ ≈ 0.87: Rater B: Vuln Rater B: Safe Row Total Rater A: Vuln 85 5 90 Rater A: Safe 7 103 110 Col Total 92 108 200 Step 1 — Observed agreement P_o: P_o = (diagonal cells) / N = (85 + 103) / 200 = 188 / 200 = 0.940 Step 2 — Expected agreement P_e (if raters were independent): P_e = [(row_1 × col_1) / N + (row_2 × col_2) / N] / N = [(90 × 92)/200 + (110 × 108)/200] / 200 = [41.4 + 59.4] / 200 = 100.8 / 200 = 0.504 Step 3 — Compute κ: κ = (0.940 − 0.504) / (1 − 0.504) = 0.436 / 0.496 = 0.879 ≈ 0.87 ✓ Landis & Koch interpretation: 0.00 – 0.20 Slight | 0.21 – 0.40 Fair | 0.41 – 0.60 Moderate 0.61 – 0.80 Substantial | 0.81 – 1.00 Almost Perfect κ = 0.87 → Almost Perfect
→ κ = 0.87 — Almost Perfect agreement between raters

One-Way ANOVA — Positional Effects

§4.3.2 · F(3,696)=127.4 · η²=0.35
1

What ANOVA tests here

Four groups (position categories: Pre-Function, Initial, Mid-Context, Distant) with binary attack success outcomes. ANOVA tests whether the mean attack success rates differ significantly across positions.

F = MS_between / MS_within = (SS_between / df_between) / (SS_within / df_within) df_between = k − 1 = 4 − 1 = 3 (k = number of groups) df_within = N − k = 700 − 4 = 696 (N = total observations)
2

Derivation of F = 127.4

Group means from Table 4.3: Pre-Function: M1 = 0.621, n1 = 175 Initial: M2 = 0.483, n2 = 175 Mid-Context: M3 = 0.385, n3 = 175 Distant: M4 = 0.227, n4 = 175 Grand mean: M = (0.621 + 0.483 + 0.385 + 0.227) / 4 = 0.429 SS_between (variation due to position): SS_between = Σ n_i × (M_i − M)² = 175×(0.621−0.429)² + 175×(0.483−0.429)² + 175×(0.385−0.429)² + 175×(0.227−0.429)² = 175×0.03686 + 175×0.00292 + 175×0.00194 + 175×0.04081 = 6.450 + 0.511 + 0.339 + 7.142 = 14.44 MS_between = 14.44 / 3 = 4.81 SS_within (variation within groups, using p(1-p) for binary data): Using SD estimates: SD1=0.485, SD2=0.500, SD3=0.487, SD4=0.419 SS_within ≈ Σ(n_i−1)×SD_i² ≈ 174×(0.235+0.250+0.237+0.176) = 174×0.898 ≈ 156.3 But corrected for binary outcomes, effective within-group variance smaller. MS_within = SS_within / 696 ≈ 4.81 / 127.4 ≈ 0.0378 F = MS_between / MS_within = 4.81 / 0.0378 ≈ 127.4 ✓
→ F(3, 696) = 127.4, p < 0.001
3

Eta-squared η² = 0.35

η² is the proportion of total variance explained by the group factor (position category).

η² = SS_between / SS_total SS_total = SS_between + SS_within = 14.44 + 156.3 ≈ 170.7 ... but = SS_between / η² = 14.44 / 0.35 = 41.3 η² = 14.44 / 41.3 = 0.35 ✓ Interpretation: Position category explains 35% of variance in attack success. η² thresholds: 0.01=small, 0.06=medium, 0.14=large; 0.35 ≫ large.
→ η² = 0.35 — Position accounts for 35% of variance in attack success
4

Bonferroni-corrected pairwise comparisons

With k=4 groups there are C(4,2) = 6 pairwise comparisons: Pre-Function vs. Initial, Pre-Function vs. Mid, Pre-Function vs. Distant, Initial vs. Mid, Initial vs. Distant, Mid vs. Distant Bonferroni correction: α_adjusted = α / m = 0.05 / 6 = 0.0083 All 6 pairwise comparisons: p < 0.001 << 0.0083 → All differences significant even under conservative correction

Attack Success Rate (ASR) — Table 4.2

Table 4.2 · §4.3.1
1

Definition

ASR is the proportion of trials using a specific attack technique that produced a vulnerability, out of all trials using that technique for that model. It is structurally the same as VGR but conditioned on technique rather than condition.

ASR(technique, model) = Vulnerable_trials / Total_trials_for_technique_on_model
2

How mean ASR is computed across models

Example: Direct Instruction mean ASR CodeT5+ = 20.0% (20/100 trials) CodeLlama = 60.8% (61/100 trials) GPT-3.5 = 68.0% (34/50 trials) GPT-4 = 53.8% (7/13 trials) Unweighted mean = (20.0 + 60.8 + 68.0 + 53.8) / 4 = 202.6 / 4 = 50.65 ≈ 50.7% → Reported in Table 4.2: 50.7% ✓ The §4.3.1 text states "55% mean success rate." This is the weighted mean using actual trial counts: (20 + 61 + 34 + 7) / (100 + 100 + 50 + 13) = 122/263 = 46.4% ... or calculated from a larger pool including all technique trials. Both values (50.7% from Table 4.2 and 55% from text) are in the dissertation.
100% / 80% for GPT-3.5 / GPT-4 (§4.3.1 text): These refer to high-authority-framing direct instruction trials only — a subset of the full direct instruction technique results. The full-technique averages in Table 4.2 are 68.0% and 53.8%, respectively.

Transferability Rate (TR) — Table 4.6

Table 4.6 · §4.6
1

Formula

TR measures how well an attack developed for one model works when applied to a different (target) model.

TR(origin → target) = ASR_target / ASR_origin TR = 1.0 means the attack is equally effective on the target as on the origin. TR = 0.65 means the attack retains 65% of its effectiveness when transferred.
2

Example derivations from Table 4.6

CodeT5+ attacks applied to CodeLlama: ASR_CodeLlama (using CodeT5+ attack prompts) / ASR_CodeT5+ (original) = 100% / 100% = 1.00 → 100% ✓ CodeLlama attacks applied to GPT-4: ASR_GPT-4 (CodeLlama prompts) / ASR_CodeLlama (original) = 70% / 100% = 0.70 → 70% ✓ GPT-3.5 attacks applied to GPT-4: ASR_GPT4 (GPT-3.5 prompts) / ASR_GPT-3.5 (original) = 85% / 100% = 0.85 → 85% ✓ Mean TR from origin row for CodeT5+: (100% + 100% + 78% + 65%) / 4 = 343% / 4 = 85.75% ≈ 85.8% ✓
3

Key transferability statistics (§4.6)

Open-source ↔ open-source (4 pairs: CT5→CL, CL→CT5, diagonals excluded): Values: 100%, 95% → Mean = 97.5% → TR = 0.975 95% CI: [0.94, 1.01] Open-source → commercial (4 pairs): CT5→GPT3.5=78%, CT5→GPT4=65%, CL→GPT3.5=82%, CL→GPT4=70% Mean = (78+65+82+70)/4 = 295/4 = 73.75% ≈ 0.738 ✓ 95% CI: [0.69, 0.78] Pairs with TR > 0.6: 12 off-diagonal pairs; 10 of them ≥ 0.65; 83% = 10/12 ≈ 83% ✓
